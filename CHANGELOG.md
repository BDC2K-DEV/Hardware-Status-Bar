# Changelog

## 0.1.0 — 2026-10-31

Initial GitHub release of the existing Ubuntu/GNOME 50 widget: smooth memory fill, driver-relative temperature colors, application memory menu, direct Kill controls, user-local installer and uninstaller, verified download script, release checksums, and real runtime screenshots.

Known limitations: GNOME 50 only; RSS totals can double-count shared memory; CPU/SSD menu tiles only; per-sample subprocess overhead; application list is a snapshot; new or reparented processes may outlive a Kill action.
