# Security

This widget runs in the user's GNOME Shell session. It reads process accounting and hardware telemetry; it does not read document contents, collect credentials, or send telemetry. The optional download script uses GitHub over HTTPS. Kill is intentionally immediate and destructive to unsaved application state.

Report security concerns through the repository's private security reporting feature if enabled; otherwise open an issue requesting a private contact without publishing exploit details or secrets. Only the latest release is maintained. Do not use this indicator as a thermal safety controller or rely on it to prevent hardware damage.
